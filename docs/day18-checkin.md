## 一、今天做了什么

能读只是「看」，能写才是「用」。今天把 **提交 → 云函数校验 → 写进数据库 → 再读出来确认** 这条闭环打通，写入比读取多出来的三件事（校验、防重复、错误处理）一次做齐。

1. **接口实现**：`POST /api/cards`、`POST /api/quiz-records` —— 响应统一 `{ok, data, error}`，201 返回的是**数据库写入后的真实行**
2. **数据层**：`db.js` 加上写入能力（POST + `Prefer: return=representation` 拿回新行）与两个「防重复查询」；接口文件里依旧没有任何查询语句
3. **校验**：必填字段、长度上限、数值范围三类；错误信息一律中文，**说清缺了哪个字段 / 哪个字段不合规**
4. **防重复**：两条判定标准定下来并写进契约（卡片按「同科目 + 同题面」，战绩按「同一天 + 同一批卡 + 同分数」），命中返回 409 且不写库
5. **前端接线**：页面「＋ 添加卡片」从只存 localStorage 改为 `POST /api/cards`，用**数据库分配的 id** 放进列表；接口不可用时回退本机（页面不瘫），接口明确拒绝时照实提示（不偷偷存本地）
6. **部署与验证**：云函数重新部署 → 公网五项检测（写入 / 防重复 / 校验 / 闭环 / 行数核对）全通过；本地回归 28 项全过
7. **余力加练**：加了一条服务端结构化日志

## 六、余力加练：服务端日志

在入口层加了一条单行结构化日志，云函数控制台里搜 `[KQ]` 就能捞出这个函数的全部请求：

```
[KQ] 2026-10-05T12:41:47.357Z GET /api/cards 200 316ms · 返回 2 条
[KQ] 2026-10-05T12:41:47.360Z POST /api/cards 400 0ms · VALIDATION_ERROR
[KQ] 2026-10-05T12:41:47.449Z GET /api/cards/9999 404 89ms · CARD_NOT_FOUND
```

记的是「时间 / 方法 / 路径 / 状态码 / 耗时 / 结论」，**刻意不记请求体全文**：一是可能很长，二是日志里不该留下用户输入原文。本地回归时用 `KQ_QUIET=1` 关掉它，免得日志淹没断言输出。

## 七、今天最值得记的一件事：写入比读取多的这三件事

读写都只是「调数据层」，但写入多出三道关，缺一道就会出脏数据：

| # | 多出来的事 | 今天的做法 |
|---|---|---|
| 1 | **校验** | 三类规则分开写：必填（说清缺哪个）、长度（按 Unicode 码点算，中文一个字算 1，报错时带上实际字数）、范围（`level` 1~3、`score ≤ total`、日期必须是 `YYYY-MM-DD`） |
| 2 | **防重复** | 判定标准先写进契约再写代码。卡片＝同科目 + 同题面；战绩＝同一天 + 同一批卡 + 同分数。命中返回 **409**（而不是 200 假装成功），因为「没写进去」是事实，得让调用方知道 |
| 3 | **错误处理** | 一律中文、说清原因、不返堆栈；4xx 是「你的输入有问题」，5xx 是「我这边有问题」——前端据此区分「该改输入」还是「该重试」 |

一个容易忽略的细节：**接口返回的是数据库写完之后的那一行**（靠 `Prefer: return=representation`）。所以 `id`、`created_at`、`source` 都是**库的真实值**，不是前端猜的——前端把这张卡放进列表时，用的就是它最终在库里的样子。

### 数据「不会去」的地方（反向声明）

- 请求体里的 `id` / `source` / `created_at` **不会**被采信：`id`、`created_at` 由数据库生成，`source` 由服务端写死为 `user`（前端传了也没用，代码里直接忽略）
- 用户输入**不会**拼进 SQL：HTTP API 通道下没有 SQL 字符串，字段值以 JSON 请求体下发、由服务端解析绑定
- 校验失败的请求**不会**落库：三条规则全部在 `db.createCard()` **之前**判定，返回 400/409 时数据库一个字节都没动
- 前端**不会**在接口明确拒绝（409/400）时偷偷存本机——那种「看着成功、其实没进库」的假象会把问题藏起来；只有网络不通/服务端异常才回退本机，并在提示里说明

## 八、每日一问：

> **你防了哪一种重复提交或错误输入？怎么测的？**

我防的是「同一张卡存两遍」，和「字段缺了 / 超长还照写」。

判定标准先写进契约：同一科目下、题面去掉首尾空白后完全相同，就算同一张卡；战绩则是同一天、同一批卡、同样的分数才算同一条。命中就回 409，不写库。

测法就三条命令：正常发 → 201、库里多一行；原样再发 → 409；删掉题面再发 → 400，消息直接说「缺少必填字段「题面」」。

最关键是核行数：写入前 24 行 → 写入后 25 行 → 重复提交后仍 25 行。三个数字对得上，才说明防重复和校验是真在工作。
