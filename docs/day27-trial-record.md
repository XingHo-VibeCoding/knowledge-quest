## 四、A 的根因：为验收官写的技术自证，被用户当成了使用说明

**现象**（复现步骤）：打开首页 → 卡片墙 → 点右上角「＋ 添加卡片」→ 面板打开时，页面上同时有这些字样：

| 位置 | 改前文案 |
|---|---|
| 顶部状态条 | 「⏳ 正在连接**云端数据库**…」→「🟢 数据来源：**云端数据库**（接口已连通）」 |
| 页脚 | 「卡片数据实时读取自**云端数据库**（CloudBase）· 自存卡片保存在本机浏览器」 |
| 页脚链接 | 「🔍 **云端数据**检查台」 |
| 统计行 | 「共 27 张卡片（其中**你自己存的** 0 张，保存在本机浏览器）」 |

**报错原文**：无。这类卡点**不会报错**——它是理解偏差，也正是 AI 自测永远测不出来的那一类。

**根因**：Day 20 为了让页面「自证读的是真库、不是本地文件」，把「云端数据库」写进了**用户看得见的位置**。
验收官需要这行字，用户却把它读成了「这东西的内容得我自己往数据库里放」。**给两个人看的字挤在同一句里，两边都误读。**

**已尝试动作**：无（试用人独立完成，全程无人提示）。

### 每日一问：真实用户卡在哪个你从没想过的地方？

**答：卡在「云端数据库」这四个字上 —— 那不是 bug，是我给验收官写的自证文案。**

我为了证明「页面读的是真库不是本地文件」（Day 20 的验收要求），把「云端数据库」写进了顶部状态条和页脚。
一个外行看到它，理解成「**这网站的内容得我自己往数据库里存**」，于是整站的结论变成「很麻烦、没什么用」。
**我从没想过的地方是：一个通过自己验收的技术写法，会把产品说成另一种东西。**
这也回答了我一直以来的自问——「自己测着没问题」为什么不算数：因为**自己测不出自己的表达**。
