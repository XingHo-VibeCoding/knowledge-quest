## 遇到的困难点

1. **视觉反复改，判断标准不稳定**：前端第一版被自己否掉（"太素太旧"），配色和版式前后改了三轮——暗色展馆 → 去模板化（卡片姿态/叠卡/视差）→ 整体换成明亮糖果色，才达到可接受的程度。每次改完都要重新算对比度、重跑测试，"好看"这件事很耗时间。
2. **CloudBase 部署踩坑多，且很多坑在文档里查不到**：CLI 自动建的云接入路由把函数类型登记成 `SCF`（实际是 Web 函数 `WEB_SCF`），网关一直报参数无效；免费环境新建后长时间 `UNAVAILABLE`；默认测试域名打开会先弹一个腾讯云「风险提醒」中间页。这些都不是代码问题，排查全靠一点点试。
3. **口语对话式语音训练还没动手，方案不确定**：想要「对话式语音输入 + 自动评级」，但浏览器的语音识别兼容性、以及"评级"到底按什么标准打（发音？流利度？用词？）还没想清楚，不敢开写。
4. **每天 45–60 分钟的节奏经常超**：Day 15（云端部署）实际花了 3 小时以上，主要是排查环境和部署问题。
