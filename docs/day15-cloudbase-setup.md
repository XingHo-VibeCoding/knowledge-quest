# Day 15 · CloudBase 开通与部署清单（knowledge-quest）

> 目标：`/api/health` 公网可访问 + 前端 mock 版公网可访问 + 三个环境信息记档。
> 分工：代码、文档、部署参数 AI 已备好；**注册、授权、确认发布必须本人操作**（附录 B 边界）。

## 0. 安全红线（先读一遍）

- 只开通**免费体验环境**；控制台若引导开通按量计费/付费套餐，一律关掉不点。
- 不开启预置并发。数据库连接串/密钥以后只放环境变量，不进代码、Git、聊天。
- 记下三样东西（见第 1 步）——**免费额度有到期日，到期公网就打不开**。

## 1. 注册 CloudBase（约 10 分钟，本人操作）

1. 打开腾讯云 CloudBase（cloud.tencent.com/product/tcb）官网，微信或手机号登录；
2. 完成实名认证（个人认证，免费）；
3. 创建环境：**选免费体验版**，地域随便（建议上海/广州），环境名填 `knowledge-quest`；

## 2. 部署 /api/health 云函数

代码已备好：`cloudbase/functions/api/`（`index.js` + `package.json`，无第三方依赖）。

**方式 A（推荐）：装「腾讯云 CloudBase」连接器，授权后由 AI 部署**
1. 在 WorkBuddy 对话里点连接器推荐卡片安装「腾讯云 CloudBase」；
2. 按提示登录腾讯云账号完成授权（这一步就是你本人的"确认"）；
3. 告诉 AI「环境 ID 是 xxx，开始部署」，AI 执行：创建函数 `api` → 开 HTTP 云接入路由 `/api/*` → 返回公网地址。

**方式 B：控制台手动**
1. 控制台 → 云函数 → 新建云函数：函数名 `api`、运行环境 Node.js 16+、内存 128MB、超时 3 秒，上传 `cloudbase/functions/api/` 目录（压缩成 zip 上传）；
2. 创建后进入函数 → 「云接入」/「HTTP 访问服务」→ 新建路由：路径 `/api`，触发条件勾 `api` 函数，发布；
3. 记下生成的公网默认域名。

## 3. 部署前端（静态托管）

前端是纯 HTML/CSS/JS（无构建步骤），直接上传：

1. 控制台 → 静态网站托管 → 文件管理；
2. 上传 `index.html`、`css/`、`js/`、`data/` 四项（**不要传** `.workbuddy/`、`docs/`、`cloudbase/`、`.git`）；
3. 打开静态托管默认域名（形如 `https://<环境ID>.tcloudbaseapp.com`），应看到卡片墙（此时是 mock 数据，正常）。

也可由 AI 通过连接器/CLI 帮传（授权后说一声即可）。
